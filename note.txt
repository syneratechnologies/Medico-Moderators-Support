Medico — Student Support & History Management Dashboard
1. Project Goal

Medico-এর internal team-এর জন্য একটি secure Student Support & History Management Dashboard তৈরি করতে হবে।

System-এর মূল উদ্দেশ্য:

Student profile management
Student-এর complete support history রাখা
Support create ও manage করা
Manager → Moderator assignment
Excel/CSV থেকে bulk support creation
Branch / Group / Batch / Individual ভিত্তিতে bulk assignment
Moderator-এর কাজের tracking
Mandatory support outcome/note
Powerful student/support search
Role-based access control
Activity/audit history
Reporting
2. User Roles

System-এ ৩টি role থাকবে।

Super Admin

Super Admin হলো system-এর highest-level user।

Super Admin পারবে:

সব dashboard দেখতে
সব student দেখতে
সব support দেখতে
Student create/edit করতে
Support create/edit/delete করতে
Manager create/edit/disable করতে
Moderator create/edit/disable করতে
Support assign/reassign করতে
সব branch/group/batch manage করতে
সব support history দেখতে
সব activity log দেখতে
সব report দেখতে
যেকোনো data manage করতে

Super Admin-এর কোনো functional restriction থাকবে না।

Manager

Manager পারবে:

Student দেখতে
Student profile create/update করতে
Moderator account create করতে
Moderator manage করতে
Support create করতে
Manual support entry করতে
Excel/CSV upload করতে
Uploaded data validate করতে
Support assign করতে
Branch/Group/Batch অনুযায়ী filter করতে
Multiple student/support একসাথে moderator-কে assign করতে
Support history দেখতে
Student-এর previous support দেখতে
Relevant reports দেখতে

Manager Super Admin account manage করতে পারবে না।

Moderator

Moderator-এর access সীমিত থাকবে।

Moderator পারবে:

নিজের assigned support দেখতে
Assigned student-এর basic information দেখতে
Support details দেখতে
Support status update করতে
Support-এর note/outcome লিখতে
Support complete করতে
নিজের completed/pending history দেখতে
Student search করতে
Student-এর previous support history দেখতে

Moderator অন্য moderator-এর assigned support manage করতে পারবে না।

Role-based permission অবশ্যই backend level-এ enforce করতে হবে।

শুধু frontend-এ button hide করলেই হবে না।

Example:

Super Admin
    ↓
Full Access

Manager
    ↓
Student + Support + Moderator

Moderator
    ↓
Assigned Support + Allowed Student History

Backend API প্রতিটি request-এর permission verify করবে।
